CLOUD RENDER (GitHub Actions, free)
===================================
Laptop par 1 video ka render ~2.5 ghante leta tha. Yeh folder wahi render GitHub ke
free computers par 20 tukdon mein ek saath karwata hai.

Kya upload hota hai: sirf job\page.html (drawing engine) aur job\data.json (shots).
Voice / audio / API key kabhi upload nahi hoti. Audio laptop par hi video mein judta hai.

Chalane ka tareeka (episode folder mein cloud_cfg.json hona chahiye, rain\cloud_cfg.json dekho):
  cloud_render.bat rain              -> poori video, seedha "Final Videos" mein
  cloud_render.bat rain 0 30         -> sirf 0-30 sec ka test (Episodes\rain\cloud_test.mp4)

Mix (mix_full.wav) pehle laptop par ban jaana chahiye, phir cloud render.
Repo public hai: GitHub par koi bhi engine ka code dekh sakta hai.
